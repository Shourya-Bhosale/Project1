# How to Find Twilio Auth Token

## Step-by-Step:

1. **Go to**: https://console.twilio.com/
   - NOT admin.twilio.com
   - NOT the organization page

2. **You should see the main dashboard** with:
   - Account SID (starts with AC...)
   - Auth Token (click 👁️ eye icon to reveal)

3. **If you don't see it:**
   - Look for "Account Info" box
   - Or click your name/avatar → Account → General Settings

4. **The Auth Token:**
   - Is 32 characters long
   - Looks like: `abc123def456ghi789jkl012mno345pq`
   - Click the eye icon to show/hide it
   - Copy the FULL token

## Important:
- Organization SID (OR...) ≠ Account SID (AC...)
- You need the Account-level Auth Token, not Organization-level
